# Story: `wf okf export` — render the fabric as a portable OKF bundle

## As a
another team, an external agent, or any OKF consumer

## I want
`wf okf export --scope global --out ./bundle` to emit a self-contained OKF
bundle of the fabric (or any scope: project/domain/global)

## So that
the fabric's knowledge can be cloned, browsed in Obsidian/viz.html, validated
with okflint, published with Kiso, or ingested by Knowledge Catalog — without
wiki-fabric tooling.

## Acceptance criteria

- [ ] `scripts/okf_export.py` + `wf okf export [--scope <project|domain|global|all>] [--out DIR]`
- [ ] Concept docs copied with frontmatter normalized to OKF v0.2:
  - wikilinks `[[stem]]` resolved to bundle-relative markdown links `/path/to/page.md` (resolution via stem→path map, same rule as lint)
  - claim `source_refs` rendered as `sources[]` + per-claim markdown footnotes keyed by source `id` (OKF §5.1 keyed, not positional)
  - unknown fabric fields preserved (OKF §4.1: consumers must not reject)
- [ ] `index.md` per directory (grouped by type) + root `index.md` with `okf_version: "0.2"`; generated by default (OKF §8)
- [ ] `log.md` emitted in OKF §9 shape (ISO-8601 date headings, newest first) from `registry/log.md` entries in scope
- [ ] Trust fields carried through: `generated`/`verified`/`status`/`stale_after` verbatim from story-3-enabled pages
- [ ] Export is deterministic (same fabric → same bundle bytes, modulo `generated.at` on the export log entry) — consistent with our determinism gates G1/G2
- [ ] Exported bundle passes: our `lint.py --okf` AND external `okflint validate`
- [ ] Round-trip test: export → `wf okf import` → claim/source counts match source fabric
- [ ] `viz.html` generation documented (external reference_agent tool) as the human-browsing path — no need to build our own viewer

## Notes

- Determinism matters for sync: story "team sync" shares content via git; an
  exportable deterministic bundle gives teams a stable artifact to diff.
- Wikilinks stay canonical *inside* the fabric (Obsidian compatibility); conversion
  happens only at the export boundary. AIX-format's typed-link mirror pattern
  (typed edge + plain markdown mirror) is a good reference if we ever add typed links.
